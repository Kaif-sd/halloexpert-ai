# HalloExpert AI – 3D AI-Powered Interactive Assistant

## Live Demo
https://www.halloexpert.com/ai

## Project Description
HalloExpert AI is a real-time conversational web platform designed for businesses and event organizers. It features a 3D AI avatar that responds to user voice inputs using context-aware organizational data.

## Tech Stack
- Frontend: ReactJS
- Backend: Spring Boot and PHP
- Database: MySQL

## Key Features
- 3D AI avatar with voice-based interaction
- QR-based instant user access
- Real-time data collection and analytics
- Cross-device compatibility
- User account management system
