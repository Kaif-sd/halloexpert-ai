## 🧠 Project Description
**HalloExpert AI** is a real-time conversational web platform designed for businesses and event organizers. It features a 3D AI avatar that responds to user voice inputs using context-aware organizational data. This tool enhances engagement and automates information delivery in interactive environments such as conferences, exhibitions, campuses, and enterprise offices.

---

## ⚙️ Tech Stack
- **Frontend:** ReactJS  
- **Backend:** Spring Boot (core services), PHP (used for deployment on free hosting server)  
- **Database:** MySQL

---

## ✨ Key Features
- 🧍‍♂️ 3D AI avatar with voice-based interaction  
- 📷 QR-based instant user access  
- 📊 Real-time data collection and analytics  
- 📱 Cross-device compatibility  
- 🔐 User account management system
